## 5. Installation and Setup

To download and run the application, follow these instructions.

### Step 1: Clone the repository

```bash
git clone https://github.com/HiiPower05/WhaleFalls-Casus.git
```

### Step 2: Open the project

1. Launch Android Studio.
2. Select Open Project.
3. Navigate to the cloned project folder.

### Step 3: Configure the project

1. Allow Gradle to synchronise.
2. Install the required dependencies.
3. Ensure the appropriate Android SDK is configured.

### Step 4: Run the application

1. Connect an Android device or launch an emulator.
2. Select the application configuration.
3. Click Run in Android Studio.
